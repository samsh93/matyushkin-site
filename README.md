# Пасека Матюшкиных — сайт

Самодостаточная статическая версия сайта.

## Что внутри

- `index.html` — главная страница.
- `privacy.html` — шаблон политики конфиденциальности.
- `assets/site.css` — локальные стили.
- `assets/site.js` — мобильное меню, форма и интерактив.
- `assets/favicon.svg` — favicon.

Внешние CDN и обязательные npm-зависимости не используются.

## Локальный запуск

Можно открыть `index.html` напрямую в браузере.

Для проверки через HTTP-сервер:

```bash
python -m http.server 8080
```

## Важно перед боевым использованием

1. Сверить все адреса магазинов и часы работы с владельцем.
2. Заменить шаблон `privacy.html` на согласованный юридический документ.
3. Подключить реальные фотографии и, при необходимости, серверную обработку заявок/CRM.
4. При смене домена обновить `canonical` и `og:url`.

## Публикация

Репозиторий настроен для публикации сайта через GitHub Pages с GitHub Actions.
